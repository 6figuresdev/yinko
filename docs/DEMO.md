# Yinko demo video: about 3 minutes

Record the dashboard in a desktop browser. Have these open before you start: the dashboard, the BscScan page for agent 420531's transaction, and the repository.

**Open (0:00 to 0:20)**
Say: "Agent IDs turn wallet addresses into names like yinko.ai. Names can be faked, and addresses can be poisoned. People and AI agents sign what they cannot read. Yinko is the check before you sign." Show the headline, "Check before you sign."

**Act 1: a poisoned address (0:20 to 0:55)**
Click "A look-alike address". Show the red Block, the reason, and the suggested cap of 0. Say: "This address copies the first and last characters of one this wallet paid before. Yinko blocks it and says why." Open "See the request sent to Yinko" and point at the one JSON call.

**Act 2: an unlimited approval, then a fake agent (0:55 to 1:35)**
Click "An unlimited approval". Show the plain-language reason. Say: "Yinko decoded the transaction data. It would let a new contract spend all your tokens." Then click "A fake agent name". Say: "y1nko.ai, with a one, is not yinko.ai."

**Act 3: a verified agent (1:35 to 2:20)**
Click "A verified agent". Show the green Allow. Say: "This is a real agent. Yinko read agent 420531 from BNB Smart Chain, fetched its registration file, and confirmed it points back to the name. Both directions match." Scroll to "The guard is an agent too". Open the BscScan page and show agent 420531 owned by the same wallet that owns yinko.ai.

**Act 4: recorded on-chain (2:20 to 2:50)**
Type the operator token, tick "Record the verdict on-chain", and run one check. Show the transaction link in the result, then the new row appearing in "Recorded on-chain". Say: "Every verdict can be written to the YinkoRegistry contract on mainnet."

**Close (2:50 to 3:10)**
Show the README section on the MCP tool. Say: "Agents call this as one tool before any payment. One guard for people and agents." Show the repository link.

Do not show the operator token or any private key on screen. Blur the token field or record that step with the token already filled and hidden.
