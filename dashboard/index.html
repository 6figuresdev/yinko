        Use it with your Binance Agentic Wallet

        Your Agentic Wallet lives in the Binance app and has no browser extension, so there is no connect button here, on purpose. Yinko works as a check in front of the wallet. To check a payment right now, use the form at the top of this page. The commands below are for your terminal or your AI agent.

        Type them once and the commands below fill in. Nothing is sent anywhere from these boxes.

        1. Get your wallet address (or copy it from the Binance app). 
          baw wallet address --json
        2. Check before you send. Exit code 0 means allow, 10 warn, 20 block: 
          git clone https://github.com/6figuresdev/yinko.git && cd yinko/guard
./yinko-check.sh --from YOUR_WALLET_ADDRESS --to RECIPIENT_ADDRESS --amount 25
        3. Approvals are checked for you. The helper runs Yinko first, stops on a block, then shows the Binance preview and asks for your confirmation: 
          export AW=YOUR_WALLET_ADDRESS
./baw-run.sh TOKEN_CONTRACT_ADDRESS APPROVAL_CALLDATA
        4. If an AI agent drives your wallet, give it the Yinko skill so it checks before every transfer or approval, and stops on a block: 
          skills/yinko-guard/SKILL.md

        Yinko only advises. It never signs, never holds funds, and never replaces the confirmation in the Binance app.

        The guard is an agent too

        Yinko Guard has its own ERC-8004 identity, and its .ai name links to it on-chain.
